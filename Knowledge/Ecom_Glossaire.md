# Glossaire e-commerce

Référence rapide. BOS l'utilise pour rester lisible : **on emploie l'abréviation ET on rappelle ce qu'elle veut dire** la première fois qu'elle apparaît dans une session avec un débutant.

---

## Économie du business

| Sigle | Signification | Ce que ça mesure |
|---|---|---|
| **COGS** | Cost of Goods Sold | Coût de revient des marchandises vendues (produit + livraison) |
| **AOV** | Average Order Value | Panier moyen par commande |
| **LTV / CLV** | Lifetime Value | Total dépensé par un client sur toute la relation |
| **CAC** | Customer Acquisition Cost | Coût d'acquisition d'un nouveau client |
| **ROI** | Return on Investment | Bénéfice rapporté au coût |
| **Break-even** | Seuil de rentabilité | Point où les revenus égalent les coûts |
| **Marge / x4, x5** | Multiplicateur | Prix de vente ÷ COGS. « x4,5 » = on vend 4,5 fois le coût de revient |

## Publicité

| Sigle | Signification | Ce que ça mesure |
|---|---|---|
| **ROAS** | Return on Ad Spend | Revenu généré par euro de publicité |
| **ROAS BE** | ROAS Break-Even | Le ROAS minimum pour ne pas perdre d'argent |
| **ROAS Target** | — | Le ROAS qui dégage assez de marge pour scaler |
| **CPM** | Coût pour mille impressions | Prix de 1 000 affichages |
| **CPC** | Coût par clic | Prix moyen d'un clic |
| **CPA / CPP** | Coût par acquisition / par achat | Prix moyen d'une vente |
| **CPL** | Coût par lead | Prix moyen d'un contact généré |
| **CTR** | Click-Through Rate | % de personnes qui cliquent après avoir vu |
| **CVR** | Conversion Rate | % de visiteurs qui achètent |
| **NC ROAS** | New Customer ROAS | ROAS calculé **uniquement sur les nouveaux clients** — l'alerte précoce que le ROAS global masque |
| **ATC** | Add To Cart | Ajout au panier |
| **VC** | View Content | Vue d'une page produit sans achat |
| **PUR** | Purchase | Achat |

## Structure des campagnes

| Terme | Signification |
|---|---|
| **Campaign** | Le niveau le plus haut : un objectif (achat, trafic, notoriété) |
| **Ad Set** | Sous-ensemble : budget, calendrier, ciblage, placements |
| **Ad** | La publicité elle-même (créative + texte) |
| **CBO** | Campaign Budget Optimization — le budget est fixé au niveau campagne, la plateforme le répartit |
| **ABO** | Ad Set Budget Optimization — le budget est fixé par ad set, chaque créative reçoit de la diffusion |
| **Broad** | Ciblage large, sans critère d'intérêt ni de démographie |
| **LAA / LAL** | Lookalike Audience — audience similaire à une base existante |
| **Retargeting** | Ciblage des personnes ayant déjà interagi |
| **Pixel** | Code installé sur le site qui enregistre les actions des visiteurs |
| **BM** | Business Manager — la structure qui contient comptes publicitaires et actifs |
| **Ad Account** | Compte publicitaire : campagnes, budgets, facturation |

## Contenu et conversion

| Terme | Signification |
|---|---|
| **Créative** | Les éléments visuels et textuels d'une publicité |
| **Ad copy** | Le texte de la publicité (titre, corps, description) |
| **Hook** | Les 2 premières secondes — ce qui arrête le scroll |
| **UGC** | User Generated Content — contenu créé par des utilisateurs ou créateurs |
| **B-roll** | Plans d'illustration sans visage face caméra — recombinables à l'infini |
| **TOFU / MOFU / BOFU** | Top / Middle / Bottom of Funnel — les trois étages de conscience du prospect |
| **Landing page** | Page conçue pour convertir, distincte de la page d'accueil |
| **Advertorial** | Page au format éditorial qui vend sans en avoir l'air |
| **Bundle** | Offre groupée (2x, 3x, lot) |
| **Upsell / Downsell / Cross-sell** | Proposition après achat : plus cher / moins cher / complémentaire |
| **CRO** | Conversion Rate Optimization |
| **A/B test** | Comparaison de deux versions sur le même trafic, simultanément |
| **CTA** | Call To Action — l'incitation à agir |

## Opérations

| Terme | Signification |
|---|---|
| **TAM** | Total Addressable Market — taille totale du marché atteignable |
| **PMF** | Product-Market Fit |
| **PSP** | Payment Service Provider — processeur de paiement |
| **SAV** | Service après-vente |
| **QC** | Quality Control — contrôle qualité avant expédition |
| **VA** | Virtual Assistant — assistant à distance |
| **SOP** | Standard Operating Procedure — procédure écrite, réutilisable |
| **CRM** | Gestion de la relation et des données clients |
| **KPI** | Indicateur clé de performance |
| **OSS** | Guichet unique de TVA pour les ventes intracommunautaires en UE |

---

**Note d'usage BOS :** ne jamais utiliser une abréviation sans l'expliquer devant quelqu'un qui débute. Le jargon donne l'illusion de la compétence et empêche la compréhension — or c'est la compréhension qui permet de décider.
